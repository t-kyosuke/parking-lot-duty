## TypeScript

### verbatimModuleSyntax に注意
- `tsconfig.app.json` で `verbatimModuleSyntax: true` が有効
- 型（interface, type）のimportは必ず `import type { ... }` を使う
- これを忘れるとブラウザでランタイムエラーになる（ビルドも失敗する）

## 作業の進め方

### ファイル保存先の絶対パスを打ち間違えない（2026-08-03）
- `Write` でプロジェクトの絶対パスを手打ちして1文字ミス（`tyuusya`→`tyuusyo`）→ 誤ディレクトリを新規生成してしまった。
- 対策：既存ファイルのパスは会話中に出た正しいパスをコピーして使う。作成後は `ls` で正しい場所に在ることを確認する。

## 当番運用（中止・急な欠席）

### 練習中止は「後ろ倒し」より「未定に戻して回数を減らす」（2026-08-03）
- 中止日の当番を1週間ずらすと、移動先で欠席（×△）の人が当番になる事故が起きやすく、末尾が翌月にはみ出す。
- 正解：中止日の当番を **✏️で「未定」に戻す**。累計は確定月の当番から自動計算されるので**回数が自動で1減り**、
  減った人は翌月以降に自動で優先される（公平が自然に戻る）。詳細な手順は `docs/DUTY_TROUBLE_GUIDE.md`。

### カゴは物理1個のバトン。中止時は「次のカゴ日の持ってくる人」を手で直す（2026-08-03）
- 「→終わりに◯◯さんが持ち帰り」は独立データではなく **“次のカゴ日の持ってくる人”をそのまま表示**（`computeKagoTakeHome`）。
  だから持ち帰り先を変えたいときは**次のカゴ日の担当を変える**＝専用の編集UIは不要。
- 練習中止だとカゴのバトン（受け渡し）が起きず、アプリ表示と「実際にカゴを持っている人」がズレる。
  アプリは中止を自動察知しないので、**次にカゴを使う日の「持ってくる人」を実際の保持者に手で直す**（例：8/8を堀本→塚原）。
