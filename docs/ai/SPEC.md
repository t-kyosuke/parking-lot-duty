## ★当番割り当てアルゴリズム（最重要）

> **2026-05-31 改定**：「**累計回数が少ない人を優先**」する方式（旧：固定順リストをポインタで循環）。
> 実装は `src/lib/assignParking.ts` の `assignDuties` / `pickByCount`。

### 基本の考え方

各当番枠（駐車場・ビデオ・カゴ）について、その日に出席（◯）しているコーチの中から、
**これまでの累計担当回数が最も少ない人**を選ぶ。これにより全員の担当回数が均等化される。

判定の優先順位（`pickByCount`。上から順に絞り込み、候補が0人になったらその条件だけ緩める）：
1. **出席（◯）している人だけ**が候補（△・×・空欄は対象外）
2. **被り防止**：同じ日にすでに駐車場当番になった人は、ビデオの候補から外す
3. **月内上限**：その月すでに上限回数（既定 `DEFAULT_MONTHLY_LIMIT` = 2回）当番した人は外す
4. **連続防止**：直前に同じ当番をした人は外す
5. 残った候補のうち**累計回数が最少の人**。同数なら固定順（`COACH_ORDER`）で先に来る人

補足ルール：
- **駐車場**：日曜・祝日のみ（土曜は割り当てなし＝`null`）。練習日（`practice`/`special`）が対象
- **ビデオ**：全日（土曜も含む）。同じ日の駐車場当番とは被らない。練習日が対象
- **累計は月をまたいで引き継ぐ**（`getCountsForAssignment` が「現在累計−その月の確定分」を返す＝再割り当てでも二重カウントしない。駐車場/ビデオ/カゴの3種に対応）
- **連続防止の起点**は前月末の当番者（`getPreviousLastCoach` が選択月より前の確定済み月から取得）
- **月内上限**：同じ人は1か月に既定2回まで。月内カウントは月ごとにリセット。`assignDuties` の引数で変更可

### カゴ（連鎖／バトンリレー。2026-06-22 導入）

> 実装は `assignKagoChain`。**駐車場/ビデオを `assignDuties` で確定した後にその結果を読むだけ**
> ＝駐車場/ビデオの当番者は一切変えない**一方通行**（カゴの都合で駐車場/ビデオの公平さを崩さない）。
> 変更前の仕様は `docs/SPEC-SNAPSHOT-before-saturday-kago.md`、復元ポイントは git tag `pre-saturday-kago`。

- カゴ（黄色うちわ＋道具が入った物理的に1個の物）が必要な全セッション
  （練習 `practice`/`special` ＋ 試合 `match`。合宿/休みは除外）を**日付順**に処理し、
  各日「カゴを持ってくる人」を1人決める。
- カゴは物理的に1個なので**「前回のカゴ・セッションに出席◯だった人」しか次に持って来られない**
  ＝候補は「**今日◯ ∩ 前回◯**」。
- 日曜・祝日の練習（駐車場あり）で**駐車場当番が前回も◯**なら、その人がそのまま運ぶ（うちわ入りのため）。
  これは**カゴ係に数えない**（`kagoCarriedByParking=true`）。
- それ以外（土曜・試合・駐車場当番が前回いなかった日）は**カゴ係を1人指名**（累計に数える）。
  同日の駐車場・ビデオはなるべく避け、累計最少・連続回避で選ぶ。月内上限はカゴには適用しない。
- 「今日◯ ∩ 前回◯」が0人＝**要確認**（`kagoNeedsConfirm=true`）。`kagoHolder` に現在の保持者を出して
  手動で引き継ぐ。要確認の日は保持者を据え置くので**連鎖は途切れない**。
- 月またぎは `getPreviousKagoSession`（前月最後のカゴ・セッションの保持者＋その日の出欠）で引き継ぐ。
- 累計は `srs_kago_counts`（**カゴ係指名分のみ**＝`isKagoCounted`。兼任・要確認は数えない）。
- `AssignmentResult` の `kagoCoach`/`kagoCarriedByParking`/`kagoNeedsConfirm`/`kagoHolder`/`isMatch` で保持。

### カゴ表示は「持ち帰り」基準（2026-07-01 改定。表示のみ・割り当てロジックは不変）

- 割り当て（`kagoCoach`＝「その日カゴを持ってくる人」）は不変。**見せ方だけ**を
  「**その日の練習後に誰がカゴを持ち帰るか**」に変更。持ち帰る人＝**次のカゴ利用日にカゴを持ってくる人**。
- 導出は純粋関数 `computeKagoTakeHome(assignments)`（次のカゴ利用日＝日付順で次のセッション。
  無ければ「翌月へ引き継ぎ」、次が要確認なら「要確認」）。
- **旧フォーマット月（カゴ連鎖導入前＝新フラグ無し。本番の4〜6月）は自動フォールバック**：
  従来どおり「その日のカゴ担当（試合日のみ）」を表示し、担当のいない日はカゴ行を出さない。
- **公開画面・LINE**：カゴが必要な全日に「🧺当日カゴ持ち帰り▶◯◯さん」を毎回表示。
- **管理画面（結果表）**：編集対象は「🧺カゴを持ってくる人▶」（＝`kagoCoach`）のまま。
  下に読み取り専用で「→終わりに◯◯さんが持ち帰り」を補足表示。
- 手動でカゴ係を変更すると指名扱い（`kagoCarriedByParking=false`・`kagoNeedsConfirm=false`＝累計に数える）。
  その日以降の保持者・要確認表示は次回フル割り当てで整う（既知の許容仕様）。

### 新しく入るコーチの扱い

後から当番に加わるコーチは、累計回数を**既存メンバーの平均**に設定してから運用に入れる
（0からだと追いつくまで偏るため）。コーチ追加UIはないので、`constants.ts` への追加＋
設定画面の「累計回数の調整」で手動セットする運用。

### 公平性（1年シミュレーションで検証済み）

DEFAULT_SCHEDULE で1年（駐車場61日／ビデオ122日）回したときの「最多−最少の差」：

| 条件 | 旧方式（順番循環） | 新方式（累計優先） |
|------|------|------|
| 全員出席（理想） | 差1回 | 差1回 |
| 出席率80%・駐車場 | 差2.0回 | **差1.0回** |
| 出席率80%・ビデオ | 差3.0回 | **差1.0回** |

- 同日の駐車場・ビデオ被り：0件／連続当番：0件
- カゴ：1年・出席80%・構造的偏りシミュレーションで要確認0回・カゴ係指名の最多−最少差3

## CSVパース仕様（`src/lib/parseCsv.ts`）

### 調整さんCSVの形式
```csv
2025年SRS3年コーチ出欠確認
コーチ陣の出欠確認こちらでお願いします
日程,茂木隼人,橋戸佑介,外山岳,...
3/29(日) 関大ラグビーフェスティバル（仮）,◯,◯,△,...
4/4(土) 13:40-16:40,◯,◯,×,...
コメント,,,祝日、日曜日は...,...
```

### パースルール
- 先頭列が「日程」の行をヘッダーとして動的に探す（それ以前の行はスキップ）
- 「コメント」で始まる行はスキップ
- 空欄（`,,`）は△（未定）と同等。◯/○/O/o→◯、×/✗/x/X→×、他は全て△
- 名前照合はスペース除去で比較（「岸下 和樹」→「岸下和樹」）。除外コーチは出欠を取り込まない
- 同日複数行は最初の行を使用（重複日は警告表示）
- エンコーディング：UTF-8（strict）で読み、失敗したら Shift_JIS にフォールバック
- 日程列から練習時間を自動抽出（`4/5(日) 13:00-14:20` → `13:00-14:20`）
- **既知の弱点**：クォート付きセル非対応（カンマを含むラベルが来ると列がズレる）。
  `〇`（漢数字ゼロ U+3007）は◯と認識されず△扱い。→ NEXT_ACTIONS.md 参照

## 対象日の判定ルール

- 土曜 `(土)` → 駐車場なし・ビデオあり／日曜 `(日)`・祝日 → 駐車場＋ビデオ
- 「試合」「交流試合」「フェスティバル」キーワード → 試合（カゴのみ）／「合宿」→ 合宿（対象外）
- 種別はUI（出欠プレビュー）で変更可能：練習／試合／合宿／休み／運動会等（=練習と同じ扱い）
- 年間試合・合宿日のデフォルト：4/26・6/14・6/28・10/12・11/6・2/23（試合）、9/13（神鍋合宿）
- `DEFAULT_SCHEDULE`（constants.ts）は **2026年度固定**。年度が変わったら更新が必要

## UI設計

### 閲覧者モード（デフォルト画面）
- 当月の当番スケジュールをカード形式で表示。月切り替え（◀▶）、当日は「TODAY」バッジ
- 練習日は3行を8文字揃えのラベルで表示：**🅿️当日の駐車場当番／🎥当日のビデオ当番／🧺当日カゴ持ち帰り**
- カゴ行はカゴ必要日に毎回出す。月内最後は「翌月へ引き継ぎ」、引き継ぎ不可は「要確認（今カゴ: ◯◯さん）」
- 試合日は「⚽試合 🧺当日カゴ持ち帰り▶◯◯さん」。合宿・休みはアイコン付きグレーアウト
- CSSはPC＝ラベルと値の横並び（矢印▶）／スマホ（≤600px）＝縦積み（矢印▼）で横あふれ防止
- データがない月は「まだ決まっていません」。下部に「🔒 管理者ログイン」

### 管理者モード（タブ切り替え）
- **タブ1 当番割り当て**：月選択 → CSVアップロード（D&D対応）→ 出欠プレビュー（◯/△/×タップ切替・
  種別/時間編集）→「当番を決定する」→ 結果表示（手動変更可）→ LINEコピー → 累計バーチャート → 公開ボタン
- **タブ2 設定**：GitHubトークン、累計回数の手動調整（±。減らすと次に優先される）、パスワード変更、
  エクスポート/インポート（JSON）、全データリセット

### LINEアナウンス出力形式
練習日「駐車場▶／ビデオ▶／🧺当日カゴ持ち帰り▶」、試合日「⚽試合：🧺当日カゴ持ち帰り▶」を日付順に出力。
カゴ行は毎日出す。月内最後は「翌月へ引き継ぎ」。

```
7月の当番は下記でお願いします。

各日の「🧺当日カゴ持ち帰り」の人が、その練習後に黄色うちわ&カゴセットを持ち帰ります。

7月4日（土曜日）：駐車場▶-　/　ビデオ▶国沢さん　/　🧺当日カゴ持ち帰り▶国沢さん
7月5日（日曜日）：駐車場▶国沢さん　/　ビデオ▶堀本さん　/　🧺当日カゴ持ち帰り▶堀本さん
7月26日（日曜日）：駐車場▶松木さん　/　ビデオ▶大串さん　/　🧺当日カゴ持ち帰り▶翌月へ引き継ぎ

よろしくお願いします。
```
※区切りの全角スペースは意図的（LINEでの見栄え）。lint の no-irregular-whitespace エラーは許容済み。
